# data/ -- Privacy Rationale

## What's excluded from this public repository, and why

`data/raw/` is listed in `.gitignore` and is **never committed**. It
contains the original `sample_-_superstore.xls` file, which includes:

- `Customer Name` (804 distinct individuals)
- `City`, `State/Province`, `Postal Code`
- `Regional Manager` names (in the People sheet)

Even though the Sample Superstore dataset is a public, widely-distributed
sample dataset (not real customer data), this project treats it as if it
contained real PII throughout, as a demonstration of correct practice for
a real client engagement. Real customer names and addresses should never
appear in a public GitHub repository regardless of the dataset's actual
provenance.

## What IS safe and included

- `data/processed/orders_clean.csv` is **regenerated by `run_analysis.py`
  on every run**, not committed as a static file, and is itself excluded
  from Git (`data/processed/*.csv` in `.gitignore`) since it's a derived
  artifact, not source-of-truth. It has `customer_name`, `city`,
  `state_province`, and `postal_code` already removed --
  `tests/test_business_rules.py::test_no_pii_columns_in_de_identified_output`
  enforces this with an automated test.
- `outputs/tables/*.csv` -- all aggregated summaries (by category, region,
  segment, discount bucket, etc.) contain no row-level customer-identifying
  data.
- `outputs/tables/customer_summary.csv` uses `customer_id` only -- never
  `customer_name`.
- `outputs/figures/*.png` -- all charts either show aggregated data or, in
  the customer-revenue Pareto chart, rank customers by number only (no
  names or IDs are printed on the chart itself).

## How to reproduce locally

1. Place the raw Excel file at `data/raw/sample_-_superstore.xlsx` (or
   `.xls` -- both are supported by `src/data_loading.py`). This file is
   not included in this repository; obtain it from the original Sample
   Superstore distribution if you don't already have it.
2. Run `python run_analysis.py` from the project root. This regenerates
   `data/processed/orders_clean.csv` and every file in `outputs/`.

## If you fork this project with real customer data

Re-verify the PII column list in `run_analysis.py`'s `PII_COLUMNS`
constant against your actual schema before publishing anything -- a
different source system may have additional identifying fields (email,
phone, IP address, etc.) that this project's specific list does not
anticipate.
