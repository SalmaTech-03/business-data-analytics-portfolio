# data/raw/

This folder is where the raw Sample Superstore Excel file belongs
(`sample_-_superstore.xlsx` or `.xls`). It is excluded from Git via
`.gitignore` because it contains customer PII (name, city, state, postal
code) -- see [`../README.md`](../README.md) for the full rationale.

If you're setting this project up from scratch, place your copy of the
dataset here before running `python run_analysis.py`.
