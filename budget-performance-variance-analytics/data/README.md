# Data Directory

## `raw/`

Holds the original source file: `Financial_Budgeting_Dataset.csv`
(6,780 rows x 20 columns). **This folder is git-ignored** (see the
repo's `.gitignore`) and is NOT committed to the public GitHub repo.

**Why:** the project's privacy policy (see `PORTFOLIO_QUALITY_CHECKLIST.md`)
treats every raw data file as sensitive-by-default before it's been
individually reviewed, and keeps the public repo lightweight. In this
specific dataset there is no customer or individual-level PII
(no names, emails, addresses) - the records are department/expense
budget entries - but the raw CSV is still excluded on principle so the
rule is consistent across any future dataset swapped into this
project, and so nobody has to re-verify "is this file safe" before
every push.

To reproduce this project, place `Financial_Budgeting_Dataset.csv`
in this folder, then run `python run_analysis.py` from the project
root.

## `processed/`

Intermediate cleaned/feature-engineered data can be cached here
during development. Also git-ignored by default; only small, clearly
safe files should ever be committed here.

## What IS committed

Only **aggregated outputs** - group-by tables (e.g. totals by
department, by expense category), summary JSON, and chart images -
generated by `run_analysis.py` into `outputs/tables/` and
`outputs/figures/`. These contain no row-level records.
